# Publish Flow: Desktop → GitHub Issue

> Desktop에서 작성한 기획을 GitHub Issue로 발행하는 상세 워크플로우

---

## 사전 조건

```
✅ 필수 파일 존재:
   - specs/screens/*.yaml (최소 1개)
   - docs/planning/01-prd.md
   - docs/planning/02-trd.md

✅ GitHub 연동:
   - gh CLI 설치 및 인증 완료
   - git remote 설정됨
```

---

## Phase 1: 기획 문서 수집

### Step 1-1: 파일 존재 확인

```bash
# 필수 파일 확인
ls specs/screens/*.yaml 2>/dev/null | wc -l
ls docs/planning/01-prd.md 2>/dev/null
ls docs/planning/02-trd.md 2>/dev/null
```

### Step 1-2: 문서 내용 읽기

```typescript
// 화면 명세 수집
const screens = Glob("specs/screens/*.yaml")
for (screen of screens) {
  Read(screen) // YAML 파싱
}

// 기획 문서 수집
Read("docs/planning/01-prd.md")
Read("docs/planning/02-trd.md")
Read("docs/planning/03-user-flow.md")   // 있으면
Read("docs/planning/05-design-system.md") // 있으면
```

### Step 1-3: 핵심 정보 추출

```yaml
# 추출할 정보
project_name: PRD에서 추출
description: PRD 첫 줄
core_features:
  - PRD의 핵심 기능 섹션에서 추출
tech_stack:
  frontend: TRD에서 추출
  backend: TRD에서 추출
  database: TRD에서 추출
screens:
  - 각 YAML 파일의 screen.name
```

## Phase 3: GitHub Issue 생성

### Step 3-1: gh CLI 사용

```bash
# Issue 생성
gh issue create \
  --title "[Design] {project_name} - 아키텍처 및 화면 명세" \
  --body "$(cat <<'EOF'
{issue_body}
EOF
)" \
  --label "design,from-desktop"
```

### Step 3-2: Issue 번호 획득

```bash
# 마지막 생성된 Issue 번호 조회
gh issue list --limit 1 --json number --jq '.[0].number'

# 또는 생성 시 출력에서 파싱
# "https://github.com/owner/repo/issues/123" → 123
```

### Step 3-3: 결과 확인

```bash
# 생성된 Issue 조회
gh issue view {number} --json url,title,state
```

## 에러 처리

### 필수 파일 없음

```
❌ 기획 문서가 없습니다.

필수 파일:
- specs/screens/*.yaml (화면 명세)
- docs/planning/01-prd.md (PRD)
- docs/planning/02-trd.md (TRD)

💡 먼저 /socrates → /screen-spec을 실행해주세요.
```

### gh CLI 미설치

```
❌ gh CLI가 설치되어 있지 않습니다.

설치 방법:
- Mac: brew install gh
- Windows: winget install --id GitHub.cli
- Linux: https://github.com/cli/cli#installation

설치 후: gh auth login
```

### gh 인증 필요

```
❌ GitHub 인증이 필요합니다.

$ gh auth login
→ 브라우저에서 GitHub 로그인
```

### git remote 없음

```
❌ git remote가 설정되지 않았습니다.

$ git remote add origin https://github.com/{owner}/{repo}.git
```

## 고급 옵션

### --draft 옵션

```bash
/desktop-bridge publish --draft
```

- Issue를 Draft 상태로 생성
- 아직 검토 중임을 표시

### --project 옵션

```bash
/desktop-bridge publish --project "Sprint 2026-02"
```

- GitHub Project에 Issue 연결
- 프로젝트 보드에서 추적 가능

### --assignee 옵션

```bash
/desktop-bridge publish --assignee @me
```

- Issue 담당자 지정
