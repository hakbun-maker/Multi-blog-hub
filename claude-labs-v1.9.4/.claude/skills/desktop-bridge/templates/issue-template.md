## 템플릿 변수

| 변수 | 설명 | 예시 |
|------|------|------|
| `{project_name}` | 프로젝트 이름 | ShopEase |
| `{description}` | 프로젝트 한 줄 설명 | 소규모 상점을 위한 이커머스 플랫폼 |
| `{features}` | 핵심 기능 목록 | 상품 관리, 장바구니, 결제 |
| `{screens}` | 화면 체크리스트 | product-list, cart, checkout |
| `{frontend}` | 프론트엔드 기술 | React + Vite + TailwindCSS |
| `{backend}` | 백엔드 기술 | FastAPI + SQLAlchemy |
| `{database}` | 데이터베이스 | PostgreSQL |
| `{prd_summary}` | PRD 요약 | 제품 요구사항 핵심 내용 |
| `{trd_summary}` | TRD 요약 | 기술 요구사항 핵심 내용 |
| `{screen_yamls}` | 화면 명세 YAML | 각 화면의 YAML 내용 |
| `{timestamp}` | 생성 시각 | 2026-01-31T10:00:00Z |
| `{issue_number}` | Issue 번호 (생성 후) | 123 |

### 화면 체크리스트 (screens_checklist)

```markdown
- [ ] `{screen_id}`: **{screen_name}** - `{route}`
  - 주요 컴포넌트: {components}
  - 데이터: {data_requirements}
```

**예시**:
```markdown
- [ ] `product-list`: **상품 목록** - `/products`
  - 주요 컴포넌트: ProductGrid, FilterSidebar, Pagination
  - 데이터: products (id, name, price, thumbnail)

- [ ] `product-detail`: **상품 상세** - `/products/:id`
  - 주요 컴포넌트: ProductInfo, ImageGallery, AddToCartButton
  - 데이터: product (전체 필드), reviews

- [ ] `cart`: **장바구니** - `/cart`
  - 주요 컴포넌트: CartItemList, OrderSummary, CheckoutButton
  - 데이터: cartItems, totalPrice
```
