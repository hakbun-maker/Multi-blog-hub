## 1. 시스템 전체 개요

### 목적

외부 플랫폼에 의존하지 않는 **자체 블로그 허브**에서 아래를 완전 자동화한다.

- 이벤트 기반 씨앗 키워드 자동 발굴
- 씨앗 키워드 → 의도별 클러스터 자동 분화
- 클러스터별 키워드 달력 자동 구성
- SEO + AEO + GEO + PASONA 기반 글 자동 생성
- 복수의 페르소나 블로그에서 각자의 스타일로 자동 발행

### 3개의 핵심 레이어

```
[씨앗 키워드]
     ↓ 의도 분화
[Intent 클러스터]  → 글의 목적 결정      ← 모든 페르소나에 동일 적용
     ↓ 구조 결정
[PASONA 프레임]    → 글의 뼈대 결정      ← Intent에 따라 자동 변형
     ↓ 표현 실행
[페르소나]         → 목적을 자기 스타일로 실행  ← 각 블로그마다 다르게
```

> 이 3개의 레이어를 **물리적으로 분리**하여 설계하는 것이 전체 시스템의 핵심이다.

## 2. 이벤트 기반 씨앗 키워드 자동 발굴

### 2-1. 수집 소스 및 방법

| 소스 | 수집 방법 | 수집 데이터 |
|------|-----------|-------------|
| 인터파크 / YES24 / 멜론티켓 | RSS or 크롤링 | 콘서트, 전시회 일정 |
| 네이버 뉴스 API | Open API | 내한공연, 경기 예정 뉴스 |
| Google Trends API | Open API | 급상승 검색어 |
| 각 스포츠 연맹 공식 사이트 | 크롤링 | 경기 일정 |
| Ticketmaster API | Open API | 글로벌 이벤트 |
| 네이버 DataLab API | Open API | 키워드 트렌드 검증 |

**수집 주기:** 매일 오전 06:00 자동 실행 (cron job)

### 2-2. 씨앗 키워드 추출 프롬프트

```python
prompt = f"""
이벤트: {event_name} / 날짜: {event_date} / 장소: {venue}

이 이벤트에서 씨앗 키워드(Seed Keyword)를 추출해줘.
씨앗 키워드란 이후 의도별로 분화될 수 있는 핵심 검색어야.

조건:
- 월간 검색량이 예상되는 키워드 우선
- 너무 광범위하지도, 너무 좁지도 않은 키워드
- 한국어 검색 기준

반드시 아래 JSON 형식으로만 반환:
{
  "seed_keywords": ["블랙핑크 공연", "블랙핑크 콘서트 2025"],
  "event_type": "공연",
  "peak_search_period": "D-60 ~ D+14",
  "estimated_volume": "high/medium/low"
}
"""
```

### 2-3. 논란 인물 블랙리스트 자동 업데이트

```
네이버 뉴스에서 "논란", "사건", "불매" 키워드 감지 시
→ 해당 인물 자동으로 REJECT 리스트에 추가
→ 이미 예약된 글 있으면 담당자에게 즉시 알림 발송
→ 관련 발행 예정 글 전체 일시 정지
```

## 3. 키워드 클러스터링 전략

### 3-1. 핵심 개념: 씨앗 키워드 → 의도별 클러스터 분화

하나의 씨앗 키워드를 검색하는 사람은 **저마다 다른 의도**를 가지고 있다.
이 의도들을 모두 포착하여 각각의 글로 커버하는 것이 클러스터링 전략이다.

```
           [씨앗 키워드]
         "블랙핑크 공연"
                ↓
   ┌────────────┼────────────┐
   ↓            ↓            ↓
정보 탐색    구매 탐색    경험 탐색
(INFO)    (AD/COMPARE)  (REVIEW/TREND)
   ↓            ↓            ↓
일정/장소   티켓/MD/굿즈   후기/감상
```

### 3-2. 의도별 클러스터 확장 예시 (씨앗: "블랙핑크 공연")

| 클러스터 | 의도 | 연관 키워드 예시 | Intent | 예상 발행 시점 |
|----------|------|-----------------|--------|---------------|
| 정보 클러스터 | 공연 정보 탐색 | 일정, 장소, 출연진, 구성 | INFO | D-60 |
| 구매 클러스터 | 티켓 구입 | 예매 방법, 좌석 등급, 가격, 취켓팅 | AD + COMPARE | D-45 |
| 준비 클러스터 | 관람 준비 | 복장 추천, 준비물, 주차, 교통 | INFO + AD | D-7 |
| 굿즈 클러스터 | MD/굿즈 구매 | 공식 MD, 응원봉, 구매 방법 | AD | D-7 |
| 후기 클러스터 | 경험/감상 공유 | 공연 후기, 세트리스트, 현장 사진 | REVIEW + TREND | D+1 |
| 감성 클러스터 | 공감/스토리 | 공연의 의미, 감동 포인트, 추억 | TREND | D+7 |

> 씨앗 키워드 1개 → **최소 8~12편의 글** 자동 생성

### 3-3. 클러스터 자동 분화 프롬프트

```python
prompt = f"""
씨앗 키워드: "{seed_keyword}"
이벤트 유형: {event_type}

이 키워드를 검색하는 사람들의 다양한 의도를 분석하고
의도별 클러스터와 연관 키워드를 생성해줘.

각 클러스터에 대해 아래 정보를 포함:
1. 클러스터명
2. 검색 의도 설명 (이 사람은 왜 검색했을까?)
3. 연관 키워드 5개 이상
4. Intent 타입 (AD/REVIEW/INFO/CRITIC/COMPARE/TREND)
5. 최적 발행 시점 (D-90 ~ D+30)
6. 수익화 방법
7. 배치 추천 블로그 유형

반드시 JSON 형식으로만 반환.
"""
```

### 3-4. 검색 점유율 극대화 원리

```
[네이버/구글 검색결과 페이지]

"블랙핑크 공연" 검색 시
→ 내 블로그 A의 "공연 일정 정보 글" 노출
→ 내 블로그 B의 "티켓 예매 방법 글" 노출
→ 내 블로그 C의 "공연 후기 글" 노출

같은 씨앗에서 나온 글들이 검색결과를 다각도로 점유
```

### 3-5. 내부 링크 허브 구조

클러스터 간 내부 링크를 자동으로 연결하여 체류시간과 SEO를 동시에 높인다.

```
블로그 A "공연 정보 글"
  └→ 블로그 B "티켓 예매 글" 링크 삽입
  └→ 블로그 B "MD 추천 글" 링크 삽입

블로그 B "티켓 예매 글"
  └→ 블로그 A "공연 정보 글" 링크 삽입
  └→ 블로그 C "공연 후기 글" 링크 삽입 (발행 후)

블로그 C "공연 후기 글"
  └→ 블로그 B "MD 추천 글" 링크 삽입
  └→ 블로그 A "다음 공연 일정 글" 링크 삽입
```

## 4. Intent 자동 분류 시스템

### 4-1. Intent 타입 정의

```python
INTENT_TYPES = {
    "AD":      "광고/프로모션",  # 구매·신청 행동 유도가 목적
    "REVIEW":  "리뷰/후기",      # 경험 기반 신뢰 형성
    "INFO":    "정보/설명",      # 정확한 지식 전달
    "CRITIC":  "비판/분석",      # 문제점 지적으로 신뢰도 확보
    "COMPARE": "비교",           # 선택 판단 보조
    "TREND":   "트렌드/이슈",    # 화제성으로 유입 극대화
}
```

### 4-2. 상업성 신호어 자동 감지

| 신호어 | 판별되는 Intent |
|--------|----------------|
| 추천, 구매, 할인, 가격, 사는 곳, 어디서 | AD |
| 후기, 솔직한, 사용해보니, 실제로, 진짜 | REVIEW |
| 방법, 하는법, 이란, 뜻, 알아보기, 총정리 | INFO |
| 문제점, 단점, 논란, 왜 안되나, 주의 | CRITIC |
| vs, 비교, 차이, 어떤게 나을까, 골라줘 | COMPARE |
| 요즘, 핫한, 떠오르는, 화제, 트렌드 | TREND |

### 4-3. Intent 자동 판별 프롬프트

```python
"""
키워드: "{keyword}"
연관키워드: {related_keywords}
클러스터: {cluster_name}

이 키워드로 블로그 글을 쓸 때 최적의 Intent를 판별해줘.

반드시 아래 JSON 형식으로만 반환:
{
  "primary_intent": "AD",
  "secondary_intent": "REVIEW",
  "monetization": "쿠팡파트너스",
  "pasona_focus": ["N", "A"],
  "reason": "구매 탐색 키워드이므로 광고성 콘텐츠가 적합"
}
"""
```

## 5. Intent × PASONA 연결 설계

### PASONA란?

PASONA는 일본 마케터 간다 마사노리가 만든 **설득형 글쓰기 프레임워크**다.
독자의 심리 흐름을 따라 글을 구성하여 자연스럽게 행동을 유도한다.

```
P — Problem    : 독자의 문제/고민을 짚어준다
A — Agitation  : 그 문제가 해결 안 되면 어떻게 되는지 자극한다
So — Solution  : 해결책을 제시한다
O — Offer      : 구체적인 제안을 한다 (가격, 혜택, 방법)
N — Narrow     : 대상을 좁혀 "바로 당신 얘기"로 만든다
A — Action     : 지금 바로 행동하게 만든다
```

### 5-1. Intent별 PASONA 강조 포인트

Intent에 따라 PASONA의 **각 요소의 비중과 순서**가 달라진다.

---

#### 🔴 AD (광고/구매 유도) — PASONA 전체 풀가동

```
독자 심리: "이거 살까 말까 고민 중"

[P] 문제 제시 (짧게)
 → "콘서트 MD, 뭘 사야 할지 모르겠죠?"
 → 독자가 공감할 수 있는 구매 고민을 한 문장으로 짚는다

[A] 자극 (짧게)
 → "공연 당일 원하는 굿즈 품절되면 정말 아쉽잖아요"
 → 구매를 미뤘을 때의 손실감을 자극한다

[So] 해결책 제시
 → "지금 바로 살 수 있는 필수 MD 리스트 정리했어요"
 → 제품/서비스를 해결책으로 자연스럽게 등장시킨다

[O] 구체적 제안 ★ 가장 비중 높음
 → 제품 혜택 3가지 이상
 → 가격 정보, 할인 정보, 구매 링크
 → "지금 살 수 있는 이유"를 구체적으로 제시

[N] 대상 좁히기 ★ 비중 높음
 → "특히 처음 블랙핑크 콘서트 가는 분들은 이것만은 꼭"
 → 독자를 세분화하여 "내 얘기"처럼 느끼게 만든다

[A] 행동 유도 ★ 비중 높음
 → "공연 3일 전에는 재고가 없을 수 있어요, 지금 확인하세요"
 → 명확한 CTA와 긴급성 요소 삽입
```

**AD용 PASONA 비중 배분:**
```
P  ██░░░░░░░░  10%
A  ██░░░░░░░░  10%
So ████░░░░░░  20%
O  ████████░░  35%  ← 핵심
N  ████░░░░░░  15%
A  ██░░░░░░░░  10%
```

---

#### 🟡 REVIEW (리뷰/후기) — O(Offer 근거) 중심

```
독자 심리: "믿을 수 있는 후기가 보고 싶다"

[P] 문제 제시
 → "블랙핑크 콘서트, 막상 가보면 어떨지 궁금하죠?"
 → 경험 전 불확실성과 기대감을 함께 표현한다

[A] 자극 (매우 짧게 or 생략 가능)
 → 리뷰 글에서 과도한 자극은 신뢰를 깎는다
 → 대신 "저도 처음엔 그랬어요"로 공감을 유도한다

[So] 해결책 = 나의 실제 경험
 → "직접 다녀온 후기를 솔직하게 씁니다"
 → 경험자로서의 신뢰를 확립하는 것이 핵심

[O] 구체적 제안 ★ 가장 비중 높음
 → 장점 구체적으로 (수치, 현장 묘사 포함)
 → 단점도 솔직하게 (신뢰도 상승)
 → 총평: 어떤 사람에게 추천하는지 명시

[N] 대상 좁히기
 → "이런 분들께는 강추 / 이런 분들은 고려해보세요"
 → 독자가 자신에게 해당되는지 스스로 판단하게 돕는다

[A] 행동 유도 (부드럽게)
 → "다음 공연도 관심 있으시면 아래 일정 확인해보세요"
 → 강요 없이 자연스러운 다음 행동으로 연결
```

**REVIEW용 PASONA 비중 배분:**
```
P  ███░░░░░░░  15%
A  █░░░░░░░░░   5%  ← 최소화
So ████░░░░░░  20%
O  █████████░  40%  ← 핵심 (장단점 + 총평)
N  ███░░░░░░░  15%
A  █░░░░░░░░░   5%  ← 부드럽게
```

---

#### 🔵 INFO (정보/설명) — P(Problem) + So(Solution) 중심

```
독자 심리: "빠르고 정확하게 알고 싶다"

[P] 문제 제시 ★ 비중 높음
 → "블랙핑크 콘서트 티켓 예매, 어떻게 해야 할지 모르겠죠?"
 → 독자가 가진 정보 공백을 정확하게 짚는다
 → 글 도입부에 핵심 정보 요약을 먼저 배치 (AEO 최적화)

[A] 자극 (짧게 or 생략)
 → "모르면 좌석 선택에서 손해 볼 수 있어요" 수준으로 가볍게

[So] 해결책 ★ 가장 비중 높음
 → 단계별 또는 항목별로 명확하게 정리
 → 출처 또는 근거 반드시 명시
 → 도표, 리스트 적극 활용

[O] 구체적 제안
 → 관련 링크, 도구, 참고 자료 제공
 → 추가로 알면 좋은 팁 포함

[N] 대상 좁히기 (가볍게)
 → "처음 예매하는 분들은 특히 3번 단계를 주의하세요"

[A] 행동 유도 (정보형)
 → "아래 링크에서 바로 예매 가능합니다"
 → 정보 소비 후 자연스러운 다음 단계로 연결
```

**INFO용 PASONA 비중 배분:**
```

A  ██░░░░░░░░  10%
So █████████░  40%  ← 핵심 (정보 본문)
O  ████░░░░░░  15%
N  ██░░░░░░░░  10%
A  █░░░░░░░░░   5%
```

#### ⚫ CRITIC (비판/분석) — P + A 중심

```
독자 심리: "문제가 뭔지 정확히 알고 싶다"

[P] 문제 제시 ★ 가장 비중 높음
 → "블랙핑크 콘서트 티켓 가격, 이게 맞는 건가요?"
 → 구체적인 데이터와 함께 문제를 명확히 제시

[A] 자극 ★ 비중 높음
 → "이 가격 구조가 지속되면 팬들이 입는 피해는..."
 → 문제의 심각성과 영향을 구체적으로 확장
 → 단, 감정적 표현과 개인 공격은 절대 금지

[So] 해결책
 → 문제에 대한 대안 또는 독자가 취할 수 있는 행동 제시
 → "그럼에도 현명하게 즐기는 방법"으로 균형 유지

[O] 구체적 제안
 → 독자가 실제로 활용할 수 있는 정보 제공

[N] 대상 좁히기
 → "이 문제가 특히 영향을 미치는 대상은..."

[A] 행동 유도
 → "이런 상황이라면 이렇게 대응하세요"
```

```
N  ██░░░░░░░░   5%
```

#### 🟢 COMPARE (비교) — N(Narrow down) 중심

```
독자 심리: "둘 중 어떤 걸 선택해야 할지 모르겠다"

[P] 문제 제시
 → "블랙핑크 콘서트 좌석, R석이 나을까요 S석이 나을까요?"
 → 선택 앞에서 느끼는 막막함을 공감

[A] 자극 (짧게)
 → "잘못 선택하면 관람 만족도가 크게 달라져요"

[So] 해결책 = 비교 분석
 → 비교표 필수 삽입
 → 각 옵션의 장단점 균형있게 서술

[O] 구체적 제안
 → 가격, 스펙, 경험 차이를 수치로 제시

[N] 대상 좁히기 ★ 가장 비중 높음
 → "이런 분들은 R석 → 이런 분들은 S석"
 → 독자가 자신의 상황에 맞는 선택지를 스스로 찾게 돕는다
 → 비교 글의 핵심 가치는 여기에 있다

[A] 행동 유도
 → "본인 상황과 가장 비슷한 케이스를 선택하세요"
 → 강요 없이 선택권을 독자에게 넘긴다
```

#### 🟣 TREND (트렌드/이슈) — P + O 중심

```
독자 심리: "요즘 왜 이게 화제야? 나도 알고 싶어"

[P] 문제 제시 = 화제의 배경
 → "요즘 블랙핑크 공연 얘기가 왜 이렇게 많이 나오는 걸까요?"
 → 트렌드의 맥락과 배경을 먼저 설명

[A] 자극 (가볍게)
 → "이걸 모르면 대화에서 뒤처질 수 있어요" 수준

[So] 해결책 = 트렌드 해설
 → 왜 지금 화제인지 맥락 설명
 → 관련 수치, 데이터, 사례 포함

[O] 구체적 제안 ★ 비중 높음
 → 독자가 트렌드에 참여하거나 활용할 수 있는 방법
 → 관련 상품, 이벤트, 정보 큐레이션

[N] 대상 좁히기
 → "특히 OO에 관심 있는 분들이라면 주목"

[A] 행동 유도
 → 공유 유도, 댓글 참여 유도
 → 트렌드 참여 링크 제공
```

```
O  ███████░░░  30%  ← 핵심 (참여/활용법)
```

### 5-2. PASONA × SEO + AEO + GEO 통합 배치

PASONA 각 요소에 SEO/AEO/GEO 최적화 요소를 동시에 배치한다.

```
[제목 + 메타 디스크립션]       ← SEO: 메인 키워드 포함
         ↓
[P — 도입부]                   ← AEO: "OOO이란?" 질문-답변 구조
                                  GEO: 지역/맥락 정보 반영
         ↓
[A — 공감/자극]                ← SEO: 연관 키워드 자연 배치
         ↓
[So — 본문 핵심]               ← SEO: H2/H3 헤딩 구조
                                  AEO: 핵심 답변 먼저 (역피라미드)
         ↓
[O — 제안/증거]                ← SEO: 이미지 alt 태그, 내부 링크
                                  GEO: 장소/가격/일정 등 구조화 데이터
         ↓
[N — 대상 좁히기]              ← AEO: "어떤 사람에게 적합한가?" 답변
         ↓
[A — CTA]                      ← SEO: 앵커텍스트 최적화 링크
```

## 6. Intent별 글쓰기 지시서 (Directive)

Intent가 결정되면 해당 Directive가 자동으로 선택된다.
**페르소나는 Directive를 변경할 수 없고, 표현 방식만 바꿀 수 있다.**

### AD Directive

```yaml
목적: "독자가 구매/신청 행동을 하게 만든다"
PASONA_비중: "O 35% + N 15% + A 10% 강조"
필수포함:
  - 제품/서비스의 핵심 혜택 3가지 이상
  - 구매 링크 또는 명확한 CTA 문구
  - 가격 정보 또는 할인 정보
  - 긴급성 요소 (마감, 한정 수량, 시즌 한정 등)
금지:
  - 단점을 글 앞부분에 배치
  - 경쟁 제품 직접 비교
  - "무조건 사세요" 등 강요성 표현
```

### REVIEW Directive

```yaml
목적: "신뢰를 기반으로 독자의 판단을 돕는다"
PASONA_비중: "O 40% 강조 (장단점 균형)"
필수포함:
  - 실사용 경험 또는 경험자 인용
  - 장점/단점 균형있게 서술
  - 총평 및 추천 대상 명시
금지:
  - 일방적 칭찬만 나열
  - 출처 없는 스펙 나열
  - 단점 완전 생략
```

### INFO Directive

```yaml
목적: "독자가 필요한 정보를 빠르고 정확하게 얻게 한다"
PASONA_비중: "So 40% 강조 (정보 본문)"
필수포함:
  - 글 상단에 핵심 요약 먼저 배치 (AEO)
  - 단계별 또는 항목별 구성
  - 출처 또는 근거 반드시 명시
금지:
  - 불필요한 감정적 표현
  - 검증되지 않은 정보
  - 광고성 문구 과다 삽입
```

### CRITIC Directive

```yaml
목적: "문제점을 날카롭게 지적하여 신뢰도를 높인다"
PASONA_비중: "P 35% + A 25% 강조"
필수포함:
  - 구체적 문제점 + 수치/근거
  - 독자에게 미치는 실질적 영향
  - 대안 또는 해결책 제시
금지:
  - 감정적 표현
  - 개인 공격성 문구
  - 근거 없는 주장
```

### COMPARE Directive

```yaml
목적: "독자가 자신에게 맞는 선택을 하게 돕는다"
PASONA_비중: "N 25% 강조 (유형별 추천)"
필수포함:
  - 비교표 필수 삽입
  - 유형별 추천 ("이런 사람에겐 A, 저런 사람에겐 B")
  - 최종 추천 명시
금지:
  - 한쪽으로 편향된 서술
  - 비교 기준 없는 단순 나열
```

### TREND Directive

```yaml
목적: "화제성으로 유입을 끌어당기고 체류시간을 높인다"
PASONA_비중: "P 20% + O 30% 강조"
필수포함:
  - 왜 지금 화제인지 맥락 설명
  - 관련 수치 또는 데이터
  - 독자 참여 유도 요소
금지:
  - 확인되지 않은 루머를 사실처럼 서술
  - 과도한 어그로성 제목
```

## 7. 페르소나 설계 구조

```yaml
  도입부_패턴: "개인 경험 또는 공감 요소로 시작"

  - "무조건 사세요"
  - 과도한 감탄사 연속 사용
  - 딱딱한 존댓말

금지_영역:
  - 정치적 발언이 포함될 수 있는 이벤트
  - 19금 콘텐츠 연관 키워드
  - 검증되지 않은 티켓 재판매 사이트
```

### 🟢 3단계 — 글 생성 후 Intent 검수 (발행 직전)

```python
"""

검수 항목 (각 10점):
① Intent 목적 달성 여부
② PASONA 비중 준수 여부
③ 필수 포함 요소 완비 여부
④ 금지 요소 미포함 여부
⑤ 페르소나 톤앤매너 일치도

판정:
- 45점 이상 → 자동 발행 승인
- 44점 이하 → 수동 검토 대기열 이동
- 금지 요소 포함 → 즉시 REJECT, 재생성
"""
```

## 12. 수익화 연결 자동화

Intent 판별 시 수익화 유형도 함께 자동 태깅된다.

| Intent | 수익화 방법 | 연결 플랫폼 | PASONA 연결 포인트 |
|--------|-------------|------------|-------------------|
| AD | 쿠팡파트너스, 제휴링크 | 쿠팡, 인터파크 | O(제안) + A(행동) |
| REVIEW | 쿠팡파트너스, 체험단 | 쿠팡, 브랜드 | O(근거 있는 추천) |
| INFO | AdSense, 자연스러운 제휴링크 | Google AdSense | So(정보) 내 자연 삽입 |
| CRITIC | AdSense | Google AdSense | A(자극) 후 대안 제시 |
| COMPARE | 쿠팡파트너스, 가격비교 제휴 | 쿠팡, 다나와 | N(유형별) + A(선택) |
| TREND | AdSense, 관련 상품 큐레이션 | Google AdSense | O(참여방법) 내 삽입 |

## 13. 핵심 원칙 요약

```
① 씨앗 키워드는 하나의 주제가 아닌 다양한 의도의 출발점이다
② 키워드가 "무엇을 해야 하는가(Intent)"를 결정한다
③ Intent가 "어떤 구조로 설득할 것인가(PASONA 비중)"를 결정한다
④ 페르소나는 "어떤 말투와 스타일로 표현할 것인가"만 담당한다
⑤ 세 레이어는 물리적으로 분리하여 설계한다
⑥ 충돌 시 우선순위: Intent > PASONA > 페르소나
⑦ 클러스터는 블로그 성격에 맞게 배치하여 검색 점유율을 극대화한다
⑧ 자동화 파이프라인의 모든 단계에 검수 레이어를 삽입한다
⑨ 발행 후 성과 데이터는 반드시 피드백 루프로 시스템에 반영한다
⑩ 페르소나 문서(persona.yaml)의 완성도가 전체 품질을 결정한다
```
