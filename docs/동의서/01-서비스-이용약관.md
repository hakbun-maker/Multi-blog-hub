# Multi Blog Hub 서비스 이용약관

> 버전: 1.0 | 시행일: 2026-04-01 | consent_type: `tos`

---

## 제1조 (목적)

본 약관은 Multi Blog Hub(이하 "서비스")를 제공하는 운영자(이하 "회사")와 이를 이용하는 고객(이하 "회원") 간의 서비스 이용에 관한 제반 사항을 규정함을 목적으로 합니다.

---

## 제2조 (정의)

1. **"서비스"**란 회사가 제공하는 멀티 블로그 관리, AI 콘텐츠 생성, 자동화 발행, 수익 분석 등 일체의 온라인 서비스를 의미합니다.
2. **"회원"**이란 본 약관에 동의하고 서비스에 가입하여 이용하는 자를 의미합니다.
3. **"수익화 로켓"**이란 키워드 자동 탐색, AI 글쓰기, 품질 검수, 자동 발행을 포함하는 자동화 파이프라인 기능을 의미합니다.
4. **"블로그 허브"**란 회원이 등록한 복수의 독립 블로그를 통합 관리하는 시스템을 의미합니다.

---

## 제3조 (약관의 효력 및 변경)

1. 본 약관은 서비스 화면에 게시하거나 기타의 방법으로 회원에게 공지함으로써 효력이 발생합니다.
2. 회사는 관계 법령을 위반하지 않는 범위에서 약관을 개정할 수 있습니다.
3. 약관 개정 시 시행일 7일 전부터 서비스 내 공지하며, 회원에게 불리한 변경의 경우 30일 전 개별 통지합니다.
4. 개정 약관 시행일 이후 서비스를 계속 이용하는 경우 변경된 약관에 동의한 것으로 간주합니다.
5. 변경된 약관에 동의하지 않을 경우 서비스 이용을 중단하고 탈퇴할 수 있습니다.

---

## 제4조 (회원가입 및 계정)

1. 회원가입은 이용 신청자가 본 약관에 동의한 후 회사가 정한 양식에 따라 정보를 기입하여 신청합니다.
2. 회사는 다음 각 호에 해당하는 경우 가입을 거절하거나 사후에 계정을 해지할 수 있습니다.
   - 타인의 정보를 도용한 경우
   - 허위 정보를 기재한 경우
   - 서비스 운영을 고의로 방해한 경우
3. 회원은 가입 시 제공한 정보가 변경된 경우 즉시 수정하여야 합니다.
4. 계정 보안은 회원 본인의 책임이며, 제3자에게 계정을 양도·대여할 수 없습니다.

---

## 제5조 (요금제 및 결제)

1. 서비스는 Lite, Basic, Pro, Growth, Scale의 5단계 요금제로 제공됩니다.
2. 각 요금제별 제공 기능, 이용 한도, 요금은 서비스 내 요금제 페이지(`/settings?tab=plan`)에 명시합니다.
3. 유료 요금제는 월간 또는 연간 결제로 제공되며, 연간 결제 시 할인이 적용될 수 있습니다.
4. 요금제 업그레이드는 즉시 적용되며, 잔여 기간에 대한 차액이 정산됩니다.
5. 요금제 다운그레이드는 현재 결제 주기 종료 시점부터 적용됩니다.
6. 다운그레이드 시 상위 요금제 전용 기능(다국어 발행, SNS 자동배포, 자동 글쓰기 파이프라인 등)으로 생성된 데이터는 읽기 전용으로 보존되며, 해당 기능의 신규 이용은 제한됩니다.

---

## 제6조 (서비스의 제공 및 변경)

1. 서비스는 연중무휴, 1일 24시간 제공을 원칙으로 합니다.
2. 다만, 시스템 점검, 장비 보수 등의 사유로 서비스가 일시 중단될 수 있습니다.
3. 회사는 서비스의 일부 또는 전부를 변경할 수 있으며, 변경 사항은 사전에 공지합니다.

---

## 제7조 (AI 콘텐츠 생성)

1. 서비스는 외부 AI API(Claude, GPT-4o, Gemini 등)를 활용하여 블로그 콘텐츠를 생성하는 기능을 제공합니다.
2. AI가 생성한 콘텐츠의 **저작권은 회원에게 귀속**됩니다.
3. 단, AI 생성 콘텐츠는 다음의 한계를 가지며, 회원은 이를 인지하고 동의합니다.
   - AI가 생성한 정보의 정확성, 최신성을 보장하지 않습니다.
   - 생성된 콘텐츠가 제3자의 저작권을 침해하지 않음을 보장하지 않습니다.
   - 회원은 AI 생성 콘텐츠를 발행 전에 검토할 책임이 있습니다.
4. 자동 발행 파이프라인(수익화 로켓)을 통해 품질 점수 45점 이상의 글은 회원의 별도 승인 없이 자동 발행될 수 있으며, 이에 대한 **최종 책임은 회원에게 있습니다.**
5. AI 생성 콘텐츠에 대한 블로그 플랫폼(Tistory, WordPress 등) 및 검색엔진(Google 등)의 정책 준수 여부는 회원이 확인하여야 합니다.

---

## 제8조 (외부 API 비용)

1. 서비스는 회원이 직접 발급한 외부 API 키를 사용하여 기능을 제공합니다.
2. 다음 API 사용에 따른 비용은 **회원이 직접 해당 API 제공자에게 부담**합니다.
   - AI 글쓰기: Claude API, OpenAI API, Gemini API
   - 키워드 탐색: 네이버 광고 API, Google Ads API(KWP), 네이버 DataLab API
   - 이미지 생성: Google Imagen 3 API
3. 자동화 파이프라인 실행 시 API 호출이 자동으로 발생하며, 이에 따른 비용도 회원이 부담합니다.
4. 회사는 예상 API 호출량 및 비용 추정 정보를 대시보드를 통해 참고용으로 제공하나, 실제 비용과 차이가 있을 수 있습니다.

---

## 제9조 (회원의 의무)

1. 회원은 다음 행위를 하여서는 안 됩니다.
   - 타인의 정보를 도용하거나 허위 정보를 등록하는 행위
   - 서비스를 이용하여 법령 또는 공서양속에 반하는 콘텐츠를 생성·배포하는 행위
   - 서비스의 안정적 운영을 방해하는 행위
   - 블로그 플랫폼의 이용약관을 위반하는 행위
   - AI를 이용하여 허위·기만적 콘텐츠를 대량 생산하는 행위
   - Google AdSense 프로그램 정책을 위반하는 행위
2. 회원은 관련 법령, 본 약관, 서비스 이용 가이드라인을 준수하여야 합니다.

---

## 제10조 (서비스 이용 제한)

1. 회사는 회원이 제9조의 의무를 위반한 경우, 사전 통지 후 서비스 이용을 제한하거나 계정을 해지할 수 있습니다.
2. 긴급한 경우(법령 위반, 타인 권리 침해 등) 사전 통지 없이 즉시 조치할 수 있으며, 사후에 통지합니다.

---

## 제11조 (면책사항)

1. 회사는 다음 각 호의 사유로 인한 손해에 대해 책임을 지지 않습니다.
   - 외부 API(Claude, OpenAI, Gemini, 네이버, Google 등) 제공자의 서비스 장애 또는 변경
   - 블로그 플랫폼(Tistory, WordPress 등)의 정책 변경 또는 서비스 장애
   - Google AdSense의 계정 정지, 정책 변경, 수익 정산 지연
   - AI가 생성한 콘텐츠의 정확성 또는 품질
   - 회원의 API 키 관리 부주의로 인한 비용 발생 또는 보안 사고
   - 자동 발행된 콘텐츠로 인한 블로그 플랫폼 제재
2. 서비스가 제공하는 수익 예측, Revenue Score, BlogGrade 등의 분석 데이터는 참고용이며, 실제 수익을 보장하지 않습니다.

---

## 제12조 (환불 정책)

1. 유료 요금제 결제 후 7일 이내에 서비스를 실질적으로 이용하지 않은 경우 전액 환불합니다.
2. 7일 경과 후에는 잔여 기간에 대한 일할 계산 환불을 원칙으로 합니다.
3. 외부 API 사용에 따른 비용은 회사의 환불 범위에 포함되지 않습니다.

---

## 제13조 (계약 해지 및 탈퇴)

1. 회원은 언제든지 서비스 설정에서 탈퇴를 요청할 수 있습니다.
2. 탈퇴 시 다음 데이터가 처리됩니다.
   - 회원의 API 키: 즉시 영구 삭제
   - 블로그 설정, 키워드, 스케줄: 즉시 삭제
   - 수익 분석 데이터: 30일 보관 후 삭제 (세무 목적)
   - 동의 이력: 법적 의무 보관 기간(3년) 동안 보관 후 삭제
3. 이미 발행된 블로그 콘텐츠는 해당 블로그 플랫폼에 존재하며, 서비스 탈퇴와 무관합니다.

---

## 제14조 (지적재산권)

1. 서비스의 소프트웨어, UI, 디자인, 알고리즘(BlogGrade, Revenue Score, PASONA 프롬프트 등)에 대한 지적재산권은 회사에 귀속됩니다.
2. 회원이 서비스를 통해 생성한 콘텐츠에 대한 저작권은 회원에게 귀속됩니다.
3. 회사는 서비스 개선 목적으로 익명화·통계화된 이용 데이터를 활용할 수 있습니다.

---

## 제15조 (분쟁 해결)

1. 서비스 이용과 관련하여 분쟁이 발생한 경우, 회사와 회원은 성실히 협의하여 해결합니다.
2. 협의가 이루어지지 않는 경우, 회사 소재지 관할 법원을 제1심 법원으로 합니다.
3. 본 약관은 대한민국 법률에 따라 해석됩니다.

---

## 부칙

1. 본 약관은 2026년 4월 1일부터 시행합니다.
2. 본 약관 시행 전에 가입한 회원에게는 시행일로부터 30일간 개정 약관이 고지되며, 별도 거부 의사가 없는 경우 동의한 것으로 간주합니다.
