# 제3자 API 키 위탁 보관 동의서

> 버전: 1.0 | consent_type: `api_key_storage`
> 수집 시점: API 키 최초 등록 시 (Just-in-Time Consent)
> 표시 위치: `/settings?tab=api-keys` — 키 등록 인라인 패널

---

## 1. 동의 대상

회원이 서비스 이용을 위해 직접 발급하여 등록하는 다음 외부 API 인증 정보:

| 카테고리 | API 키 종류 | 저장 형태 |
|---------|-----------|----------|
| AI 글쓰기 | Claude API Key, OpenAI API Key, Gemini API Key | AES-256 암호화 |
| 이미지 생성 | Google Imagen 3 API Key | AES-256 암호화 |
| 키워드 탐색 | 네이버 광고 API Key + Secret, 네이버 검색 API Client ID + Secret, Google Keyword Planner Developer Token | AES-256 암호화 |
| 수익화 | 쿠팡파트너스 Partner ID, Amazon Associates Tracking ID | AES-256 암호화 |

---

## 2. 보관 목적

등록된 API 키는 오직 다음 목적으로만 사용됩니다.

1. 회원의 지시에 따른 외부 API 호출 (AI 글쓰기, 키워드 탐색, 이미지 생성, 제휴 링크 생성)
2. 자동화 파이프라인(수익화 로켓) 실행 시 예약된 API 호출
3. API 키 유효성 테스트 (회원이 "테스트" 버튼 클릭 시)

---

## 3. 보안 조치

1. **암호화**: 모든 API 키는 AES-256-GCM 방식으로 암호화하여 저장합니다. 평문으로 저장되지 않습니다.
2. **복호화 키 격리**: 복호화 키(ENCRYPTION_KEY)는 서버 환경변수에만 존재하며, 데이터베이스에 저장되지 않습니다.
3. **접근 제어**: Supabase RLS 정책에 의해 회원 본인의 API 키만 접근 가능합니다.
4. **마스킹 표시**: 서비스 화면에서 API 키는 앞 4자리와 뒤 4자리만 표시합니다 (예: `sk-ant-...4f2a`).
5. **클라이언트 미노출**: API 키는 서버사이드(Next.js API Routes)에서만 복호화되어 사용되며, 브라우저로 전송되지 않습니다.
6. **전송 구간 암호화**: API 키 등록/수정 시 HTTPS(TLS 1.2 이상)를 통해 전송됩니다.

---

## 4. 회사의 의무

1. 등록된 API 키를 회원의 서비스 이용 목적 외에 사용하지 않습니다.
2. API 키를 제3자에게 제공, 공유, 판매하지 않습니다.
3. 보안 사고 발생 시 즉시 회원에게 통지하고 필요한 조치를 취합니다.
4. 회원의 API 키로 발생하는 외부 서비스 비용에 대해 책임지지 않습니다.

---

## 5. 회원의 권리

1. **즉시 삭제 요청**: 회원은 언제든지 등록된 API 키를 개별적으로 삭제할 수 있습니다 (`/settings?tab=api-keys` > 삭제 버튼).
2. **동의 철회**: 본 동의를 철회할 수 있으며, 철회 시 등록된 모든 API 키가 즉시 영구 삭제됩니다. 해당 API 키를 사용하는 기능(AI 글쓰기, 키워드 탐색 등)은 이용이 중단됩니다.
3. **서비스 탈퇴 시**: 회원 탈퇴 즉시 모든 API 키가 영구 삭제되며, 복구할 수 없습니다.

---

## 6. 보관 기간

- **활성 상태**: 회원이 서비스를 이용하는 동안
- **비활성 처리**: 회원이 API 키를 비활성화한 경우에도 암호화된 상태로 보관 (재활성화 가능)
- **삭제**: 회원이 삭제를 요청하거나, 서비스를 탈퇴하거나, 본 동의를 철회한 경우 즉시 영구 삭제

---

## 7. 동의 거부 시 불이익

본 동의를 거부하실 수 있으나, 거부 시 외부 API를 활용하는 다음 기능을 이용할 수 없습니다: AI 글쓰기, 키워드 탐색, 이미지 생성, 수익화 로켓 파이프라인, 쿠팡파트너스/Amazon 자동 삽입.
