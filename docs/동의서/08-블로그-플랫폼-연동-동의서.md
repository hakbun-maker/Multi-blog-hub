# 외부 블로그 플랫폼 연동 동의서

> 버전: 1.0 | consent_type: `blog_platform_{platform}`
> 수집 시점: 블로그 플랫폼별 최초 연동 시 (Just-in-Time Consent)
> 표시 위치: 블로그 생성/설정 — 플랫폼 연결 시 OAuth/인증 직전 모달

---

## 1. 연동 대상 플랫폼

| 플랫폼 | 연동 방식 | 요청 권한 |
|--------|----------|----------|
| Tistory | OAuth 2.0 (`/apis/post/write`) | 글 작성, 글 수정, 글 삭제, 카테고리 조회 |
| WordPress | Application Password (`wp-json/wp/v2/posts`) | 글 작성, 글 수정, 글 삭제, 미디어 업로드 |

---

## 2. 연동 목적

1. **콘텐츠 발행**: AI가 생성한 글 또는 직접 작성한 글을 회원의 블로그에 게시
2. **자동 발행**: 수익화 로켓 파이프라인에서 품질 검수 통과 글을 자동으로 게시
3. **예약 발행**: 스케줄러에 등록된 시간에 맞춰 예약 게시
4. **이미지 업로드**: 글에 포함된 이미지를 블로그 플랫폼에 업로드

---

## 3. 자동 발행 안내

1. 수익화 로켓 활성화 시, 품질 검수 45점 이상의 글은 **회원의 별도 승인 없이** 연동된 블로그에 자동 게시됩니다.
2. 자동 발행 시간은 블로그 설정의 코어 발행 시간(한국어: 06:00 KST 등) 기준으로 실행됩니다.
3. 발행 실패 시 최대 3회 자동 재시도(지수 백오프)하며, 3회 실패 시 보류 처리됩니다.

---

## 4. 인증 정보 관리

| 플랫폼 | 저장 정보 | 보안 |
|--------|----------|------|
| Tistory | OAuth Access Token + Refresh Token | AES-256 암호화 |
| WordPress | Application Password | AES-256 암호화 |

1. 인증 정보는 서버사이드에서만 사용되며, 클라이언트로 전송되지 않습니다.
2. 토큰 만료 시 자동 갱신을 시도합니다.

---

## 5. 회원의 권리

1. **연동 해제**: 언제든지 블로그 설정에서 플랫폼 연동을 해제할 수 있습니다. 해제 시 인증 정보가 즉시 삭제됩니다.
2. **자동 발행 중단**: 수익화 로켓을 비활성화하거나, 해당 블로그의 자동 발행 설정을 OFF할 수 있습니다.
3. **이미 발행된 글**: 서비스에서 연동을 해제하더라도, 이미 블로그 플랫폼에 발행된 글은 해당 플랫폼에 유지됩니다. 삭제가 필요한 경우 블로그 플랫폼에서 직접 삭제해야 합니다.

---

## 6. 주의사항

1. 연동된 블로그 플랫폼의 이용약관을 준수할 책임은 회원에게 있습니다.
2. 블로그 플랫폼의 API 정책 변경, 서비스 장애 등으로 인해 발행이 실패할 수 있으며, 이에 대해 회사는 책임지지 않습니다.
3. Tistory의 경우 Open API 이용 정책에 따라 자동 발행 횟수가 제한될 수 있습니다.
4. WordPress의 경우 서버 환경(호스팅, 플러그인 등)에 따라 API 동작이 다를 수 있습니다.

---

## 동의 확인

```
[Tistory 연동 시]
☑ Tistory 블로그에 대한 글 작성/발행 권한 부여에 동의합니다.
                                    [동의 후 Tistory 연결]

[WordPress 연동 시]
☑ WordPress 블로그에 대한 글 작성/발행 권한 부여에 동의합니다.
                                    [동의 후 WordPress 연결]
```
