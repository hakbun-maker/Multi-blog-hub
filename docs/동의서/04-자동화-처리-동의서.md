# 자동화 처리 동의서

> 버전: 1.0 | consent_type: `automation`
> 수집 시점: 수익화 로켓 최초 활성화 시 (Just-in-Time Consent)
> 표시 위치: `/monetize` — 로켓 활성화 모달

---

## 1. 자동화 처리 개요

Multi Blog Hub의 "수익화 로켓" 기능은 다음 작업을 **회원의 별도 개입 없이 자동으로 실행**합니다. 본 동의서는 이러한 자동화 처리의 범위와 내용을 안내하고, 회원의 명시적 동의를 받기 위한 것입니다.

---

## 2. 자동화 처리 범위

### 2-1. 키워드 자동 탐색 (새벽 cron 실행)

| 항목 | 내용 |
|------|------|
| 실행 시점 | 매일 새벽 (pg_cron 스케줄 기반) |
| 처리 내용 | 네이버 광고 API, Google KWP, 네이버 DataLab 호출 → Revenue Score 산출 → 키워드 등급(S/A/B/C/D) 자동 분류 |
| 회원 API 사용 | 회원이 등록한 키워드 탐색 API 키 자동 호출 (비용 발생 가능) |
| 결과 | 키워드 달력에 자동 등록 |

### 2-2. AI 글 자동 작성

| 항목 | 내용 |
|------|------|
| 실행 시점 | 스케줄러에 확정된 발행일 도래 시 |
| 처리 내용 | 회원이 선택한 AI(Claude/GPT/Gemini) 호출 → PASONA 구조 + SEO/AEO/GEO 적용 → HTML 콘텐츠 생성 |
| 회원 API 사용 | 회원이 등록한 AI API 키 자동 호출 (비용 발생) |
| 글 1편 예상 비용 | Claude Sonnet 약 $0.03~0.05 / GPT-4o 약 $0.02~0.04 / Gemini Flash 약 $0.005~0.01 |

### 2-3. 품질 검수 및 자동 발행

| 항목 | 내용 |
|------|------|
| 검수 기준 | 검수 A(골드/시즌): 발견17 + 설득18 + 수익15 = 50점 만점 / 검수 B(이벤트): 이벤트35 + 기술15 = 50점 만점 |
| **자동 발행 조건** | **총점 45점 이상 → 회원 승인 없이 자동 발행** |
| 보류 조건 | 총점 45점 미만 → 보류 큐 → 회원 검토 대기 |
| 발행 대상 | 회원이 연동한 블로그 플랫폼(Tistory, WordPress)에 직접 게시 |

### 2-4. 블로그-키워드 자동 배분

| 항목 | 내용 |
|------|------|
| 처리 내용 | BlogGrade × KeywordGrade 매트릭스 기반 자동 배분 |
| 배분 기준 | S급 키워드 70% → S급 블로그, 나머지 하위 등급에 성장 쿼터 배정 |
| 결과 | 캘린더에 자동 스케줄 등록 |

### 2-5. 주간 피드백 루프 (매주 월요일 자동)

| 항목 | 내용 |
|------|------|
| 처리 내용 | AdSense 데이터 수집 → BlogGrade 재산출 → 등급 승급/강등 판정 → 배분 매트릭스 자동 조정 → 키워드 가중치 보정 |
| 회원 API 사용 | AdSense API OAuth 토큰 자동 호출 |

### 2-6. SNS 자동 배포 (설정 시)

| 항목 | 내용 |
|------|------|
| 실행 시점 | 블로그 글 발행 후 (즉시/지연/수동 중 설정에 따라) |
| 처리 내용 | 블로그 글 → PASONA 기반 SNS 콘텐츠 자동 변환 → Instagram/X/Threads 자동 게시 |
| 이미지 생성 | 설정 ON 시 Google Imagen 3 API 자동 호출 (비용 발생) |

### 2-7. 쿠팡파트너스/Amazon 자동 삽입 (설정 시)

| 항목 | 내용 |
|------|------|
| 처리 내용 | AI가 글 내용 분석 → 관련 상품 자동 추천 → 제휴 링크 자동 삽입 |
| 삽입 위치 | PASONA O(Offer) 섹션 앞 |

## 3. 회원의 개입 지점

자동화 처리 중 회원이 직접 개입할 수 있는 지점은 다음과 같습니다.

1. **키워드 달력 확인/수정**: 자동 등록된 키워드를 수정, 삭제, 날짜 변경 가능
2. **보류 글 검토**: 45점 미만 보류 글에 대해 승인/수정/거절 결정
3. **자동화 ON/OFF**: 수익화 로켓을 언제든 비활성화 가능
4. **개별 기능 토글**: SNS 자동배포, 쿠팡파트너스 삽입을 개별적으로 ON/OFF 가능

---

## 4. 자동 발행 콘텐츠에 대한 책임

1. 자동 발행된 콘텐츠에 대한 **최종 책임은 회원에게 있습니다.**
2. 자동 발행된 글이 블로그 플랫폼 정책, 구글 검색 정책, 광고 정책 등을 위반하는 경우 발생하는 불이익에 대해 회사는 책임지지 않습니다.
3. 회원은 자동 발행된 콘텐츠를 수시로 확인하고, 문제가 있는 경우 수정 또는 삭제할 책임이 있습니다.

---

## 5. API 비용 발생 안내

자동화 파이프라인 실행 시 회원이 등록한 외부 API가 자동 호출되며, 이에 따른 비용이 발생합니다. 비용은 회원이 해당 API 제공자에게 직접 부담하며, 회사는 비용에 대해 책임지지 않습니다.

---

## 6. 동의 철회

1. 회원은 언제든지 수익화 로켓을 비활성화하여 자동화 처리를 중단할 수 있습니다.
2. 비활성화 시 진행 중인 자동화 작업은 완료 후 중단되며, 새로운 자동화 작업은 시작되지 않습니다.
3. 이미 자동 발행된 콘텐츠는 해당 블로그 플랫폼에 그대로 유지됩니다.
