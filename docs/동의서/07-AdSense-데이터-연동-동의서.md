# AdSense 데이터 연동 동의서

> 버전: 1.0 | consent_type: `adsense_oauth`
> 수집 시점: AdSense OAuth 최초 연결 시 (Just-in-Time Consent)
> 표시 위치: 수익 대시보드 — AdSense 연결 버튼 클릭 시 OAuth 직전 모달

---

## 1. 연동 목적

Google AdSense 계정을 연동하여 다음 목적으로 수익 데이터를 수집·분석합니다.

1. **수익 대시보드 제공**: 블로그별 일별/주별/월별 수익 현황 시각화
2. **BlogGrade 산출**: 실제 AdSense 성과(CPC, RPM, 트래픽, 카테고리 일관성) 기반 블로그 등급 자동 산출
3. **피드백 루프**: 실제 수익 vs 예측 수익 비교 → 키워드 가중치 자동 보정 → Revenue Score 정확도 향상
4. **배분 최적화**: BlogGrade × KeywordGrade 매트릭스 기반 키워드-블로그 배분 정교화

---

## 2. 수집 데이터 항목

AdSense API를 통해 다음 데이터를 **일별 자동 수집**합니다.

| 데이터 항목 | 설명 | 활용 목적 |
|-----------|------|----------|
| page_views | 페이지 조회수 | 트래픽 분석, session_score 산출 |
| ad_impressions | 광고 노출수 | 광고 성과 분석 |
| ad_clicks | 광고 클릭수 | CTR 산출 |
| ctr | 클릭률 | BlogGrade 참고 지표, 콘텐츠 품질 분석 |
| avg_cpc_krw | 평균 클릭당 비용 (원) | BlogGrade 핵심 지표 (가중치 40%) |
| revenue_krw | 수익 (원) | 수익 대시보드, RPM 산출 |

---

## 3. 데이터 처리 방식

1. **수집 주기**: 매일 자동 (AdSense API 일별 배치)
2. **저장 위치**: `post_ad_performance` 테이블 (포스트 단위 URL 매핑)
3. **집계 처리**: 매주 월요일 피드백 루프에서 30일 집계 → BlogGrade 재산출
4. **접근 제어**: Supabase RLS 정책으로 회원 본인 데이터만 접근 가능

---

## 4. OAuth 토큰 관리

1. AdSense OAuth 토큰은 AES-256 암호화로 저장됩니다.
2. 토큰은 서버사이드에서만 사용되며, 클라이언트로 전송되지 않습니다.
3. 토큰 만료 시 자동 갱신을 시도하며, 실패 시 재연결을 요청합니다.

---

## 5. 회원의 권리

1. **연동 해제**: 언제든지 AdSense 연동을 해제할 수 있습니다. 해제 시 OAuth 토큰이 즉시 삭제됩니다.
2. **데이터 삭제 요청**: 수집된 수익 데이터의 삭제를 요청할 수 있습니다.
3. **연동 해제 시 영향**:
   - BlogGrade가 갱신되지 않으며, 마지막 산출 등급이 유지됩니다.
   - 수익 대시보드에 신규 데이터가 표시되지 않습니다.
   - 피드백 루프의 자동 보정 기능이 중단됩니다.
   - 키워드-블로그 자동 배분은 마지막 BlogGrade 기준으로 계속 동작합니다.

---

## 6. 보관 기간

| 데이터 | 보관 기간 |
|--------|----------|
| 일별 수익 데이터 | 서비스 이용 기간 + 탈퇴 후 30일 |
| BlogGrade 이력 | 서비스 이용 기간 + 탈퇴 후 30일 |
| OAuth 토큰 | 연동 해제 또는 탈퇴 시 즉시 삭제 |

---

## 7. 주의사항

1. AdSense 수익 데이터는 참고용이며, Google AdSense 대시보드의 공식 수치와 차이가 있을 수 있습니다.
2. AdSense API의 데이터 반영 지연(통상 24~48시간)으로 인해 실시간 수익과 차이가 있을 수 있습니다.
3. Google AdSense의 API 정책 변경 시 데이터 수집이 제한될 수 있습니다.
