# Multi Blog Hub 개인정보 처리방침

> 버전: 1.0 | 시행일: 2026-04-01 | consent_type: `privacy`

## 제1조 (개인정보의 수집 항목 및 수집 방법)

### 1. 회원가입 시 수집 항목

| 구분 | 수집 항목 | 수집 목적 | 필수 여부 |
|------|----------|----------|----------|
| 필수 | 이메일 주소, 비밀번호, 이름(닉네임) | 회원 식별, 서비스 제공, 고객 지원 | 필수 |
| 선택 | 프로필 이미지, 연락처 | 서비스 개선, 알림 발송 | 선택 |

### 2. 서비스 이용 과정에서 수집되는 항목

| 구분 | 수집 항목 | 수집 목적 |
|------|----------|----------|
| 블로그 정보 | 블로그 이름, URL, 플랫폼, 도메인, 카테고리 | 블로그 관리 및 서비스 제공 |
| API 인증 정보 | AI API 키(Claude, OpenAI, Gemini), 키워드 API 키(네이버 광고, Google Ads), 이미지 API 키(Imagen), 제휴 마케팅 ID(쿠팡파트너스, Amazon Associates) | 외부 서비스 연동 및 기능 제공 |
| OAuth 토큰 | AdSense OAuth 토큰, SNS OAuth 토큰(Instagram, X, Threads), 블로그 플랫폼 OAuth 토큰(Tistory) | 외부 플랫폼 연동 |
| 수익 데이터 | AdSense 수익(CPC, CTR, RPM, 페이지뷰, 클릭수, 수익금) | 수익 분석 및 BlogGrade 산출 |
| 이용 기록 | 키워드 검색 이력, 글 작성/발행 이력, 스케줄 설정, 자동화 실행 로그 | 서비스 제공 및 개선 |
| 자동 수집 | IP 주소, 브라우저 정보, 접속 로그, 쿠키 | 보안, 통계 분석 |

### 3. 수집 방법

- 회원가입 및 서비스 이용 과정에서 회원이 직접 입력
- OAuth 인증 과정에서 외부 플랫폼으로부터 자동 수집
- 자동화 파이프라인 실행 과정에서 시스템 자동 생성
- 웹사이트 방문 시 쿠키를 통해 자동 수집

## 제2조 (개인정보의 이용 목적)

1. **서비스 제공 및 운영**: 블로그 관리, AI 콘텐츠 생성, 자동 발행, 키워드 탐색, 수익 분석
2. **수익 최적화**: BlogGrade 산출, Revenue Score 계산, 키워드-블로그 배분 최적화, 피드백 루프 실행
3. **자동화 처리**: 수익화 로켓 파이프라인(키워드 탐색 → AI 글쓰기 → 검수 → 발행), SNS 자동 배포
4. **고객 지원**: 문의 대응, 알림 발송, 서비스 공지
5. **서비스 개선**: 이용 통계 분석, 기능 개선, 오류 수정
6. **법적 의무 이행**: 관련 법령에 따른 기록 보관

## 제4조 (개인정보의 제3자 제공)

1. 회사는 원칙적으로 회원의 개인정보를 제3자에게 제공하지 않습니다.
2. 다만, 다음의 경우에는 예외로 합니다.
   - 회원이 사전에 동의한 경우
   - 법령에 의거하거나 수사 기관의 요청이 있는 경우
3. **외부 API 호출 시 데이터 전송**: 서비스 기능 제공을 위해 회원의 API 키를 사용하여 외부 서비스(Anthropic, OpenAI, Google, 네이버 등)에 요청을 전송합니다. 이 과정에서 키워드, 콘텐츠 프롬프트 등이 해당 API 제공자에게 전달됩니다. 각 API 제공자의 개인정보 처리방침은 해당 서비스에서 확인하시기 바랍니다.

## 제6조 (개인정보의 암호화 및 보안 조치)

1. **API 키 암호화**: 모든 외부 API 키는 AES-256 암호화로 저장되며, 복호화 키는 서버 환경변수로 격리 관리됩니다.
2. **OAuth 토큰 암호화**: SNS, AdSense, 블로그 플랫폼 OAuth 토큰은 암호화하여 저장합니다.
3. **데이터 접근 제어**: Supabase RLS(Row Level Security) 정책을 적용하여 사용자 본인의 데이터만 접근 가능합니다.
4. **전송 구간 암호화**: 모든 데이터 전송은 HTTPS(TLS 1.2 이상)를 통해 이루어집니다.
5. **클라이언트 노출 방지**: API 키는 서버사이드에서만 처리되며, 클라이언트로 전송되지 않습니다.

## 제7조 (회원의 권리 및 행사 방법)

1. 회원은 언제든지 다음의 권리를 행사할 수 있습니다.
   - 개인정보 열람 요청
   - 개인정보 정정·삭제 요청
   - 개인정보 처리 정지 요청
   - 동의 철회
2. 권리 행사는 서비스 내 설정 페이지 또는 고객센터를 통해 가능합니다.
3. 동의 철회 시 해당 기능의 이용이 제한될 수 있습니다.
   - 예: API 키 보관 동의 철회 → 해당 API 키 즉시 삭제 → 관련 기능 이용 불가

## 제8조 (쿠키 정책)

1. 서비스는 로그인 상태 유지 및 이용 편의를 위해 쿠키를 사용합니다.
2. 회원은 브라우저 설정을 통해 쿠키 저장을 거부할 수 있으며, 이 경우 일부 서비스 이용에 제한이 있을 수 있습니다.
