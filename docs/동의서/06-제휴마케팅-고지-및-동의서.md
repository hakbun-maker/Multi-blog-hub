# 제휴마케팅 자동 삽입 고지 및 동의서

> 버전: 1.0 | consent_type: `affiliate_marketing`
> 수집 시점: 쿠팡파트너스 ID 또는 Amazon Associates Tag 최초 등록 시 (Just-in-Time Consent)
> 표시 위치: `/blogs/[id]/settings?tab=monetize` — 자동 삽입 활성화 시 인라인 패널

---

## 1. 제휴마케팅 자동 삽입 개요

본 기능은 AI가 블로그 글 내용을 분석하여 관련 상품의 제휴 링크를 자동으로 삽입하는 서비스입니다.

| 항목 | 내용 |
|------|------|
| 지원 플랫폼 | 쿠팡파트너스 (한국어 블로그 기본), Amazon Associates (영어/일본어/독일어 등 기본) |
| 삽입 방식 | AI가 글 내용 + ad_category 분석 → 상품 자동 추천 → PASONA O(Offer) 섹션에 제휴 링크 삽입 |
| 삽입 조건 | Intent별 설정에 따라 자동/수동 결정 (AD/REVIEW/COMPARE: 기본 ON, INFO/CRITIC/TREND: 기본 OFF) |
| 최대 삽입 수 | 글당 1~3개 (회원 설정) |

---

## 2. 수익 귀속

1. 제휴 링크를 통한 구매 발생 시 **수익은 전액 회원에게 귀속**됩니다.
2. 회사는 제휴 마케팅 수익의 일부를 수취하지 않습니다.
3. 수익 정산은 각 제휴 플랫폼(쿠팡파트너스, Amazon Associates)의 정산 정책에 따릅니다.

---

## 3. 회원의 책임

1. **플랫폼 약관 준수**: 쿠팡파트너스, Amazon Associates 각 프로그램의 이용약관을 준수할 책임은 회원에게 있습니다.
2. **공정거래 표시**: 관련 법령에 따라 제휴 링크가 포함된 콘텐츠임을 표시해야 할 의무가 있을 수 있습니다. 회원은 해당 법령을 확인하고 필요한 조치를 취해야 합니다.
3. **계정 유지**: 제휴 플랫폼 계정의 유지 및 관리는 회원의 책임입니다.
   - Amazon Associates: 180일 내 3건 판매 미달성 시 계정 비활성화
   - 쿠팡파트너스: 통장 등록 및 정산 설정

---

## 4. AI 상품 추천 기준

1. 메인 키워드 + 광고 카테고리 기반 상품 카테고리 추출
2. 쿠팡/Amazon 검색 API: 리뷰 100건 이상, 평점 4.0 이상, 로켓배송(쿠팡) 조건
3. AI가 글 문맥에 가장 자연스러운 상품 1~3개 최종 선택
4. **회사는 특정 상품의 추천을 보장하거나 상품 품질에 대해 책임지지 않습니다.**

---

## 5. 설정 및 해제

1. 회원은 `/blogs/[id]/settings?tab=monetize`에서 다음을 설정할 수 있습니다.
   - 자동 삽입 ON/OFF
   - 글당 최대 상품 수 (1/2/3개)
   - Intent별 삽입 조건 (유형별 ON/OFF)
   - 제휴 플랫폼 선택 (쿠팡/Amazon/둘 다)
2. 자동 삽입을 OFF하면 이후 생성되는 글에 제휴 링크가 삽입되지 않습니다. 이미 발행된 글의 제휴 링크는 유지됩니다.

---
