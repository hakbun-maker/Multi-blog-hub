# SNS 계정 연동 동의서

> 버전: 1.0 | consent_type: `sns_oauth_{platform}`
> 수집 시점: SNS 플랫폼별 최초 연결 시 (Just-in-Time Consent)
> 표시 위치: `/blogs/[id]/settings?tab=sns` — 플랫폼 연결 버튼 클릭 시 OAuth 직전 모달

---

## 1. 연동 대상 플랫폼

| 플랫폼 | 연동 방식 | 요청 권한 |
|--------|----------|----------|
| Instagram | Instagram Graph API (Meta Developer App) | 게시물 작성, 이미지 업로드, 예약 발행 |
| X (Twitter) | Twitter API v2 (OAuth 2.0) | 트윗 작성, 스레드 게시, 예약 발행 |
| Threads | Threads API (Meta Graph API) | 게시물 작성, 스레드 연결, 예약 발행 |

---

## 2. 연동 목적

연동된 SNS 계정은 다음 목적으로만 사용됩니다.

1. **자동 콘텐츠 배포**: 블로그 글 발행 후 PASONA 기반 SNS 콘텐츠로 자동 변환하여 게시
2. **이미지 게시**: Google Imagen 3으로 생성된 이미지를 SNS에 첨부 게시
3. **연결 테스트**: 회원이 "테스트" 버튼을 눌렀을 때 연동 상태 확인

---

## 3. 자동 게시 범위

1. 자동 게시는 회원이 설정한 조건에 따라 실행됩니다.
   - **발행 트리거**: 블로그 글 발행 즉시 / N시간 후 / 수동 승인
   - **Intent별 배포 조건**: AD, REVIEW, INFO, TREND, CRITIC, COMPARE 유형별 플랫폼 선택
2. 자동 게시되는 콘텐츠는 블로그 글의 전체 내용이 아니라, PASONA 구조 중 P(문제)→A(공감)→S(힌트)까지만 공개하여 블로그 유입을 유도하는 형태입니다.
3. 게시물에는 블로그 링크가 CTA로 포함됩니다.

---

## 4. OAuth 토큰 관리

1. **암호화 저장**: OAuth 액세스 토큰은 AES-256 암호화로 `blog_settings` JSONB에 저장됩니다.
2. **갱신**: 토큰 만료 시 자동 갱신을 시도하며, 실패 시 재연결을 요청합니다.
3. **마스킹**: 서비스 화면에서 토큰 값은 노출되지 않으며, 연결 상태만 표시됩니다.

---

## 5. 회원의 권리

1. **개별 해제**: 각 SNS 플랫폼의 연동을 개별적으로 해제할 수 있습니다 (`/blogs/[id]/settings?tab=sns` > 연결 해제 버튼).
2. **자동 게시 중단**: 연동을 유지하면서도 자동 게시만 OFF할 수 있습니다.
3. **프롬프트 수정**: 플랫폼별 SNS 변환 프롬프트를 직접 편집할 수 있습니다.
4. **연동 해제 시**: 해당 플랫폼의 OAuth 토큰이 즉시 삭제됩니다. 이미 게시된 SNS 콘텐츠는 해당 플랫폼에 유지됩니다.

---

## 6. 주의사항

1. SNS에 자동 게시된 콘텐츠에 대한 책임은 회원에게 있습니다.
2. 각 SNS 플랫폼의 커뮤니티 가이드라인 및 이용약관을 준수할 책임은 회원에게 있습니다.
3. SNS 플랫폼의 API 정책 변경으로 인해 자동 게시 기능이 제한될 수 있습니다.
4. Instagram은 비즈니스 계정 또는 크리에이터 계정이 필요할 수 있습니다.
