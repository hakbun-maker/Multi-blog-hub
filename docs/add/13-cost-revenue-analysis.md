## 10. 장기 비용 최적화 전략: CDN + R2 이전

### 현재 구조의 문제

```
현재: 독자 → Supabase Storage (직접 서빙)
              ├─ 저장 비용: $0.021/GB/월 (누적, 삭제 로직 없음)
              └─ 대역폭: $0.09/GB (독자가 볼 때마다 과금)
```

- 이미지는 이미 WebP(sharp, quality=85)로 변환 중이나, **누적 저장 + 대역폭** 이중 과금 구조
- 12개월 후 340GB 누적 → 저장만으로 월 $7.14, 대역폭까지 합하면 월 $29.64

### 추천 구조: Cloudflare R2 이전

```
최적화: 독자 → Cloudflare CDN(무료, 자동) → Cloudflare R2
                ├─ 저장 비용: $0.015/GB/월 (29% 절감)
                └─ 대역폭: $0 (무료!) ← 핵심
```

### 비용 비교 (12개월 시점, 340GB 누적 기준)

| 비교 항목 | Supabase Storage | Cloudflare R2 | 절감률 |
|----------|-----------------|---------------|--------|
| 저장 단가 | $0.021/GB/월 | $0.015/GB/월 | **29%** |
| 대역폭 단가 | $0.09/GB | **$0** | **100%** |
| 12개월 저장 비용 (340GB) | $7.14/월 | $5.10/월 | -$2.04 |
| 12개월 대역폭 (500GB/월) | **$22.50/월** | **$0** | **-$22.50** |
| **월 합계** | **$29.64 (₩40,014)** | **$5.10 (₩6,885)** | **83% 절감** |

### 최적화 로드맵 (우선순위순)

| 우선순위 | 전략 | 효과 | 난이도 | 시급성 |
|---------|------|------|--------|--------|
| 1 | **이미지 저장소를 R2로 이전** | 대역폭 비용 100% 제거 | 중 | 유저 500명+ 시점 |
| 2 | **이미지 삭제 정책 추가** (90일 미조회 시 삭제 등) | 누적 저장 비용 억제 | 하 | 유저 300명+ 시점 |
| 3 | **WebP quality 85→75 + 리사이즈** (800×600) | 저장·대역폭 약 50% 감소 | 하 | 즉시 적용 가능 |
| 4 | Cloudflare CDN | R2 사용 시 자동 적용 | 자동 | R2 이전 시 자동 |

## 11. 핵심 결론

> **인프라 비용만 놓고 보면 극도로 높은 수익률(94%+)의 SaaS 구조.**

- AI API 비용을 사용자에게 전가하는 모델 덕분에 플랫폼 한계비용이 매우 낮음
- 150명 규모에서 인프라 비용은 **월 ₩33만~₩45만** 수준
- 월 매출 **₩583만** 대비 **순이익 ₩539만~₩550만**
- Lite(무료) 유저의 비용 부담은 미미 (전체의 1.4%)
- **Scale > Pro > Growth > Basic** 순으로 인당 수익성이 높음
- 가장 큰 비용은 PG 수수료(71.6%)이며, 서버 비용은 전체의 28.4%에 불과
