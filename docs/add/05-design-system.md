## 3. 컴포넌트 명세

### 수익대시보드 컴포넌트

#### RocketStatusCard
```
- 역할: 파이프라인 전체 현황 한눈에 보기
- 표시: 대기 중 / 작성 중 / 검수 중 / 이번 달 발행 수
- 색상: 상태별 아이콘 + 골드 강조
- 크기: full-width, 4분할 그리드
```

#### RevenueSummaryCard
```
- 역할: 수익 요약 (이번 달 / 지난 달 / 예상 수익)
- 표시: 금액(원) + 전월 대비 증감률(%)
- 색상: 증가=그린, 감소=레드
- 크기: 3분할 카드
```

#### RevenueLineChart (Recharts)
```
- 역할: 현재까지 수익 + 예상 수익 트렌드
- X축: 날짜 (일별)
- Y축: 수익 (원)
- 라인: 실제 수익(골드 실선) + 예상 수익(골드 점선)
- 툴팁: 날짜 + 실제/예상 수익 표시
```

#### BlogGradeTable
```
- 역할: 블로그별 등급 + 핵심 지표 표
- 컬럼: 블로그명 | 등급 | 이번 달 수익 | 발행 글 수 | RPM
- 등급: 색상 배지 (S=골드, A=실버, ...)
- 정렬: 수익 내림차순 기본
```

#### MultiDimensionChart (Recharts)
```
- 역할: 다차원 수익 분석 그래프
- 탭 선택: 블로그별 / 광고별 / 언어별 / 블로그유형별
- 차트 유형: BarChart (비교) + PieChart (비율)
- 색상: 카테고리별 자동 배색
```

### 키워드탐색기 컴포넌트

#### KeywordTypeSelector
```
- 역할: 탐색 유형 선택 (골드 / 이벤트 / 시즌)
- 형태: 탭 또는 라디오 버튼 그룹
- 아이콘: 골드=별, 이벤트=캘린더, 시즌=시계
```

#### KeywordResultCard
```
- 역할: 키워드 탐색 결과 카드
- 표시: 키워드명 | Revenue Score | 등급 배지 | 검색량 | CPC | 경쟁도
- 액션: "달력에 추가" 버튼
- 색상: 등급별 좌측 보더 색상
```

#### RevenueScoreBar
```
- 역할: Revenue Score 시각화 (0~100)
- 형태: Progress bar (골드 그라디언트)
- 세부: 트래픽/수익/난이도/트렌드 세부 분할 표시
```

---

### 스케줄러 컴포넌트

#### KeywordCalendar
```
- 역할: 월간 키워드 배분 캘린더
- 형태: 월간 그리드 뷰 (react-big-calendar 또는 커스텀)
- 셀: 날짜별 배정된 키워드 카드 목록
- 인터랙션: 드래그 앤 드롭으로 날짜 변경
```

#### DistributionEnginePanel
```
- 역할: 자동 배분 실행 + 결과 프리뷰
- 입력: 기간 선택, 블로그 선택
- 출력: 블로그별 배분 결과 테이블
- 버튼: "자동 배분 실행" (골드 버튼)
```

### Neurion 확장 컴포넌트 (기능 4~7)

#### RevenueGuidePanel (기능 5 — 수익화 가이드 아코디언)
```
- 역할: 목표 월수익 입력 → 전략 역산 출력 + MD 다운로드
- 위치: 수익대시보드 최상단 (RocketStatusCard 위, 기본: 접힌 상태)
- 형태: 아코디언 슬라이드 다운 (Framer Motion 애니메이션)
  - 헤더 버튼: "수익화 가이드 ▼" — 항상 보이는 상단 버튼, 클릭 시 펼쳐짐
  - 펼쳐지면 나머지 대시보드 컴포넌트가 아래로 밀림
- 색상: 골드 라이트 배경 (--rocket-gold-light)

패널 내부 레이아웃 (펼쳐진 상태):
  ┌───────────────────────────────────────────────┐
  │  📊 수익화 가이드                      [▲ 닫기] │
  ├───────────────────────────────────────────────┤
  │  목표 월수익  [ 1,000,000 원 ]  [전략 계산]    │
  ├───────────────────────────────────────────────┤
  │  ← 계산 결과 (계산 버튼 클릭 후 표시) →       │
  │  ✦ 필요 블로그 수: 3개                         │
  │  ✦ 블로그 구성: 리뷰형 2개 + 정보형 1개        │
  │  ✦ 페르소나: 30대 직장인 / IT 관심 등          │
  │  ✦ 일일 자동 발행: 6개 (98% 자동)              │
  │  ✦ 예상 달성 기간: 약 3개월                    │
  │  ✦ 키워드 전략: S/A등급 AD형 중심              │
  ├───────────────────────────────────────────────┤
  │          [ ↓ MD 파일로 저장 ]                 │  ← 결과 하단 고정 버튼
  └───────────────────────────────────────────────┘

- [MD 파일로 저장] 버튼:
  - 결과 영역 하단에 항상 표시 (계산 전엔 비활성화 disabled)
  - 아이콘: Download (lucide)
  - 클릭 시 브라우저 다운로드로 .md 파일 저장
  - 파일명 형식: revenue-guide-{목표금액}-{날짜}.md
```

#### ImageGenToggle (기능 6 — 이미지 생성 선택)
```
- 역할: SNS 이미지 생성 도구 선택 + 잠금
- 형태: Toggle Switch (ON/OFF) + Select (도구 선택)
  - OFF 상태: 선택 비활성화
  - ON 상태: DALL-E 3 / Ideogram / Flux 라디오 선택
  - isLocked = true 시: 선택 불가 + "변경하려면 잠금 해제 필요" 툴팁
- 잠금 해제: 별도 "변경" 버튼 클릭 → 확인 모달
- 색상: 잠긴 상태 = 그레이, 활성 = 퍼플(AI)
```

#### SNSFormatPromptInput (기능 6 — 플랫폼별 프롬프트 입력)
```
- 역할: 플랫폼별 SNS 포맷 프롬프트 직접 입력
- 형태: 플랫폼 탭 (Instagram / X / Threads) + Textarea
- 텍스트: placeholder = "예: 인스타그램 감성 글로 작성, 해시태그 10개 포함, 이모지 자연스럽게"
- 글자 수: max 500자 + 카운터 표시
- 저장: 각 플랫폼별 독립 저장
```

#### BlogSettingsTabNav (기능 4/6/7 — 블로그 설정 탭)
```
- 역할: 블로그 설정 페이지 내 탭 네비게이션
- 탭 목록:
  ① 기본 설정 (기존)
  ② 언어/지역 (기능 4)
  ③ SNS 자동화 (기능 6)
  ④ 수익화 연동 (기능 7)
- 형태: 언더라인 탭 스타일 (기존 프로젝트 상속)
```
