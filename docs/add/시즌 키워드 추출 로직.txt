# 데이터 수집 단계 (API별 역할)
## 네이버 검색 API → 트렌드 흐름 파악
DataLab 검색어 트렌드 API 활용

수집항목 :
- 해당 월 상대 검색량 지수 (0~100)
- 기기별 비율 (PC / 모바일)
- 성별·연령별 분포

호출 파라미터 :
startDate : 2024-04-01
endDate   : 2024-04-30  → 동일 월 반복 호출
timeUnit  : month

## 네이버 광고 API → 수익성 데이터 파악
키워드 도구 API 활용

수집항목 :
- 월간 PC/모바일 검색량
- 경쟁 강도 (low / mid / high)
- 입찰가 추정치 (CPC)

# 시즌 키워드 판별 로직
수집한 6개 월 데이터로 아래 3가지 패턴을 계산합니다.

① 반복 상승 패턴 (핵심 조건)

2024년 4월 지수 + 2025년 4월 지수
→ 2년 연속 동일 월에 지수 상승이 확인되면 시즌 키워드로 분류

판별 공식 :
해당월 평균지수 > 전월 평균지수 × 1.2  →  시즌 키워드 ✅

② 상승 기울기 (선점 타이밍)

전월 대비 지수 증가율이 20% 이상이면
→ 지금 발행해야 다음달 트래픽을 선점 가능

기울기 = (이번달 지수 - 전월 지수) / 전월 지수 × 100
기울기 ≥ 20%  →  즉시 발행 대상

③ 연도별 편차 (안정성 검증)

2024년 4월 지수와 2025년 4월 지수의 차이가
20포인트 이내  →  안정적 시즌 키워드 ✅
20포인트 초과  →  1회성 이슈 키워드, 제외

# Scout 에이전트용 프롬프트
[역할]
너는 네이버 검색 트렌드와 광고 데이터를 분석하는 
키워드 전략가다.

[입력 데이터]
- 블로그 유형 : {블로그 유형}
- 분석 기준월 : {현재월} / {다음월}
- 검색 트렌드 데이터 : {DataLab API 응답값}
- 광고 지표 데이터 : {광고 API 응답값}

[분석 조건]
1. 2024년과 2025년의 {현재월}, {다음월} 데이터를 비교하라
2. 아래 3가지 조건을 모두 충족하는 키워드만 추출하라
   - 조건A : 2년 연속 동일 월 검색지수 상승 확인
   - 조건B : 전월 대비 검색량 증가율 20% 이상
   - 조건C : 2개년 동일월 지수 편차 20포인트 이내
3. 조건 충족 키워드를 아래 기준으로 1차 정렬하라
   - 우선순위1 : CPC 높은 순
   - 우선순위2 : 모바일 검색 비율 60% 이상
   - 우선순위3 : 경쟁강도 mid 이하

[출력 형식]
키워드 / 검색량 / CPC / 경쟁강도 / 시즌안정성 / 추천발행월
위 항목을 테이블로 출력하고
각 키워드에 대해 시즌 상승 근거를 1줄로 요약하라

[제외 조건]
- 특정 연도 단발성 이슈 키워드 (스캔들, 사건사고)
- 검색량이 2개년 모두 1,000 미만인 키워드
- 경쟁강도 high이면서 CPC 낮은 키워드
