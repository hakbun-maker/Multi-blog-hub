네이버 검색 API 기반 키워드 선별 전략

# 먼저 알아야 할 현실
네이버 검색 API는 2가지 종류가 있고, 목적이 다릅니다.

API | 제공 데이터 | 용도
검색광고 API | 월간 검색량, PC/모바일 비율, 경쟁도, 입찰가 | ✅ 키워드 전략에 핵심
검색 API (일반) | 블로그/뉴스 검색 결과 | 경쟁 콘텐츠 분석용

핵심은 검색광고 API입니다. 여기서 CPC 관련 지표를 뽑을 수 있습니다.

#선별 전략 : 3단계 필터링

1단계 — 검색량 필터 (모수 확보)

월간 검색량 기준
PC + 모바일 합산 1,000 ~ 30,000 사이
→ 너무 작으면 유입 없음
→ 너무 크면 경쟁 과열

2단계 — 경쟁도 필터 (노출 가능성)

검색광고 API의 "경쟁정도" 필드 활용

낮음(low)   → 상위 노출 용이, 단 CPC도 낮을 수 있음
중간(mid)   → 가장 이상적인 구간 ✅
높음(high)  → 대형 키워드, 블로그로 뚫기 어려움

3단계 — CPC 추정 필터 (수익성)

검색광고 API → plAvgDepth(평균 광고 노출 순위) + 입찰가 데이터 활용

고CPC 카테고리 특징:
- 보험 / 금융 / 대출
- 건강기능식품 / 병원
- 법률 / 세무
- 부동산 / 이사

→ 블로그 타겟인 건강/영양제는 CPC 높은 편 ✅

# 황금 키워드 공식
이 세 조건을 동시에 만족하는 키워드를 노립니다.

✅ 월 검색량 3,000 ~ 20,000
✅ 경쟁도 "중간(mid)"
✅ 입찰가 상위 추정 카테고리

= 경쟁은 뚫을 수 있고, 클릭당 단가는 높은 구간

# 실전 보정 로직 2가지

① PC 비율 보정
PC 비율이 높을수록 CPC 높음
(PC 사용자 = 구매력 높은 30~50대 직장인)

PC비율 40% 이상이면 CPC 가중치 부여

② 계절/시점 보정
최근 3개월 검색량 트렌드가 상승 중인 키워드 우선
→ 검색광고 API의 monthlyPcQcCnt 월별 비교로 확인 가능

# 한 줄 요약

"검색량 중간 + 경쟁도 중간 + 고CPC 카테고리 + PC비율 높음"
이 4개가 겹치는 키워드가 블로그 애드센스 수익 극대화 포인트입니다.
