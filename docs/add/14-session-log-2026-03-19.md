## 세션 1: API 키 분류 ~ 수익화 에디터 ~ Amazon Associates

### 논의 1: API 키 분류 체계 확립

**질문**: 플랫폼이 관리하는 키와 블로거가 직접 발급하는 키를 어떻게 구분할 것인가?

**결론**:
- **플랫폼 레벨** (`.env.local`, 비용 0원): Supabase, Meta Developer App (Instagram+Threads), X API, CRON_SECRET, ENCRYPTION_KEY
- **블로거 레벨** (`ai_api_keys` 테이블, 사용자 부담): AI API (Claude/GPT/Gemini), Google Imagen 3, 키워드 탐색 (네이버 광고/검색, Google KWP), 쿠팡파트너스
- 모든 블로거 API 키는 `ai_api_keys` 테이블에 user 레벨로 AES-256-GCM 암호화 저장
- blog_settings에는 키를 저장하지 않고 설정(ON/OFF, 스타일 등)만 저장

**수정 문서**: `docs/planning/11-api-setup-guide.md` — Part A/B 구조 확립, Part D 환경변수 템플릿, Part E ai_api_keys 테이블 구조
